# MindMeal UX Case Study

MindMeal 的 UX 設計作品說明，以可直接部署的靜態 HTML、CSS 與 JavaScript 製作。

## 預覽

直接開啟 `index.html`，或在此資料夾執行：

```powershell
python -m http.server 4177
```

瀏覽 `http://localhost:4177/`。

## 操作

- 向下捲動瀏覽九個章節
- 使用右下角按鈕切換
- 鍵盤方向鍵、Page Up／Page Down、Home／End 皆可操作
- 桌機保留 16:9 簡報比例；手機自動切換為單欄閱讀

## 技術

純 HTML / CSS / JavaScript，不需安裝套件或執行建置流程。
